# Pull and Merge Request Guideline

Use the normative [guideline](gitlab-mergerequest.guidelines.md) when preparing a GitHub pull
request or GitLab merge request.

## Installation

```console
$ guidelines add gsemet/ai-guidelines-registry SWE/Gitlab/Merge_Request
$ guidelines sync
```

Alternatively, copy `gitlab-mergerequest.guidelines.md` to the target project's
`.github/guidelines/` or `.agents/guidelines/` directory.

## Scope

The guideline explains how to follow a project's own request template, use a general-purpose
fallback when no template applies, write for reviewers, and plan suitable evidence for the request.
