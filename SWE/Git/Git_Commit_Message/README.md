# Git Commit Message Guideline

Use the normative [guideline](git-commit-message.guidelines.md) when writing
commit messages.

## Installation

Copy `git-commit-message.guidelines.md` to the target project's
`.agents/guidelines/` or `.github/guidelines/` directory.

## Scope

The guideline covers Conventional Commit subjects, physical line lengths,
user-impact-focused bodies, breaking-change migration notes, signed-off-by
trailers, AI attribution, and Craftsman workflow trailers.
